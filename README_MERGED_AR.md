# ScreenGuard v3.1 — التطبيق المدموج 🛡️

**ScreenGuard v3.1** هو الدمج الاحترافي الكامل لتطبيقين في مشروع واحد:

| التطبيق الأساس (Base) | التطبيق المدموج (Features) |
|---|---|
| **ScreenMonitor** (ScreenGuard) | **App-Usage-Tracker-Controller** (مراقب الاستخدام / Muraqib) |
| لقطات الشاشة الذكية + المعرض + PIN + الثيمات + اللغتان | تحليلات الاستخدام + البيانات + محرك القيود + الحجب الفوري |

---

## 🆕 سجل تحديث v3.1 (إصلاح ثلاث مشاكل رئيسية)

### 1) إصلاح انهيار التبويبات الجديدة 🔧
- **السبب الجذري:** الاستعلام من UsageStatsManager دون فحص صلاحية "الوصول إلى بيانات الاستخدام" كان يرمي `SecurityException` فوريًا (خاصة في صفحة تفاصيل التطبيق)، إضافةً إلى استثناءات غير معالجة داخل الكوروتينات، وذاكرة تخزين مؤقت غير آمنة للخيوط في AppInfoManager.
- **الإصلاحات:**
  - فحص الصلاحية قبل أي استعلام + إظهار حالة فارغة إرشادية بدل الانهيار
  - حماية try/catch شاملة لكل مسارات تحميل البيانات (التبويبات الثلاثة + تفاصيل التطبيق)
  - ذاكرة آمنة للخيوط (ConcurrentHashMap) لتسميات وأيقونات التطبيقات
  - إضافة صلاحية `ACCESS_NETWORK_STATE` اللازمة لعمل تبويب البيانات على أجهزة كثيرة
  - **حوار صلاحيات تلقائي** عند دخول التطبيق يوجهك لمنح ما هو ناقص
  - **قسم "الصلاحيات" جديد في الإعدادات** يعرض حالة كل صلاحية (الوصول للاستخدام / العرض فوق التطبيقات / الإشعارات) بضغطة واحدة
  - **مسجل أعطال مدمج:** أي توقف مفاجئ يُسجَّل في سجل داخلي يمكن عرضه/نسخه من الإعدادات ← حول التطبيق ← سجل الأعطال

### 2) الالتقاط مرتبط بمدة الاستخدام فقط ⏱️
- **المحفّز الأساسي:** لا تُلتقط أي صورة إلا بعد مرور **المدة المحددة من الاستخدام الفعلي** (الشاشة مضاءة وتطبيق أمامي) — الافتراضي 10 دقائق استخدام، قابل للتعديل من 1 إلى 720 دقيقة. تصفير العداد عند إطفاء الشاشة.
- **المحفزات القديمة أصبحت اختيارية ومعطّلة افتراضيًا:** التقاط دوري بوقت الحائط، التقاط عند فتح أي تطبيق، التقاط عند إيقاظ الشاشة.
- **أُلغي** الالتقاط الأولي الفوري عند تشغيل الخدمة نهائيًا.

### 3) إعدادات مكتملة ومنسقة ⚙️
- قسم **الصلاحيات** الجديد (أعلى الإعدادات) مع حالة كل صلاحية لونيًا
- مفاتيح التحكم بكل محفزات الالتقاط + حقل مدة الاستخدام
- **مهلة إعادة القفل** الجديدة: فورًا / 30 ثانية / دقيقة / 5 دقائق
- أقسام الحماية المتقدمة والنسخ الاحتياطي أصبحت **بطاقات منسقة** بأيقونات وفواصل وتأثير لمس متسق مع باقي الشاشة

## ✨ الميزات الكاملة للتطبيق المدموج

### 1. محرك لقطات الشاشة (من ScreenMonitor — الأساس)
- 🎯 **المحفّز الأساسي (v3.1):** لقطة صامتة بعد مرور مدة الاستخدام الفعلي المحددة (افتراضيًا 10 دقائق من الاستخدام النشط — وليس وقت الساعة)
- 🔧 محفزات اختيارية قابلة للتفعيل/الإيقاف من الإعدادات: التقاط دوري بوقت الحائط، التقاط عند فتح التطبيق، التقاط عند إيقاظ الشاشة (كلها معطّلة افتراضيًا)
- 🚫 لا يتم أي التقاط أولي فوري عند تشغيل الخدمة
- 🖼️ معرض لقطات بشبكة 3 أعمدة + عارض كامل الشاشة بالسحب
- 🗑️ حصة تخزين متجددة (يحذف الأقدم تلقائيًا، افتراضيًا 200 لقطة)

### 2. تحليلات وقت الشاشة (مدموجة من مراقب الاستخدام)
- ⏱️ إجمالي وقت الشاشة + عدد الفتحات لكل تطبيق
- 📊 رسم بياني ساعي تفاعلي (24 عمودًا، اضغط على أي ساعة)
- 🌗 توزيع أوقات اليوم (صباح/ظهر/مساء/ليل)
- 📅 فترات: اليوم / أمس / الأسبوع / الشهر / فترة مخصصة
- 📈 مقارنة تلقائية مع الفترة السابقة (+% / -%)
- 🔀 ترتيب حسب الوقت أو الفتحات أو الاسم
- 👆 اضغط أي تطبيق لعرض **صفحة تفاصيله الكاملة**

### 3. مراقبة استهلاك البيانات (مدموجة)
- 📶 إجمالي الجهاز: WiFi مقابل بيانات الجوال (شريط نسب)
- 🏆 قائمة التطبيقات الأكثر استهلاكًا
- ⬇️⬆️ تفصيل الاستقبال/الإرسال لكل تطبيق
- 🔍 فلترة حسب نوع الشبكة والفترة

### 4. محرك القيود والحجب (مدموج — قلب التطبيق)
- 🚫 **حظر كامل** لأي تطبيق أو **مجموعة تطبيقات**
- ⏳ **حد استخدام** يومي أو أسبوعي بالدقائق
- 👥 نمطان للمجموعات: حد مستقل لكل تطبيق أو **إجمالي مشترك**
- 🕐 **جدول زمني**: نوافذ مسموحة متعددة + أيام الأسبوع النشطة
- ⚡ **حجب فوري بطبقتين**: خدمة إمكانية الوصول (صفر تأخير) + خدمة استقصاء احتياطية (1.2 ثانية)
- 🪟 **درع الشاشة المنقسمة**: تغطية دقيقة لنافذة التطبيق المحظور فقط
- 📺 اعتراض **نافذة صورة-داخل-صورة (PiP)**
- 🎛️ سياسة ذكية لتطبيق الإعدادات (لا يُحظر إلا بقرار صريح + استثناء النوافذ المنبثقة)
- 🔓 **تخطٍ مؤقت محمي بـ PIN** (1–300 دقيقة، خطوتان: مدة ثم رمز، يعود للحظر تلقائيًا وينجو من إعادة التشغيل)

### 5. الأمان الموحد (دمج كلا النظامين)
- 🔢 قفل PIN رباعي بتشفير SHA-256 مملح (متوافق مع ترقية مستخدمي الإصدار السابق)
- ❓ **سؤال استعادة** لإعادة تعيين الرمز المنسي
- 🛡️ **قفل ضد التخمين**: 5 محاولات خاطئة → انتظار 30 ثانية
- ⏱️ مهلة إعادة القفل بعد مغادرة التطبيق (افتراضيًا 15 ثانية)
- 🚪 اعتراض فتح صفحة التطبيق في الإعدادات (إيقاف إجباري/مسح بيانات)
- 📦 اعتراض شاشات إلغاء التثبيت في مثبت الحزم
- 👑 **مسؤول الجهاز**: منع الإزالة + قفل الشاشة فورًا (Lock Screen Now)

### 6. المرونة والبقاء (مدموجة)
- 🔄 إنجو من إعادة التشغيل (BOOT/LOCKED_BOOT/USER_UNLOCKED/MY_PACKAGE_REPLACED/QUICKBOOT)
- 🔍 **تدقيق الوضع الآمن (Safe Mode)**: يرصد استخدام التطبيقات المقيدة أثناء توقف الحماية
- 🕰️ **كشف التلاعب بساعة النظام** (الرجوع للخلف لتجاوز الحدود)
- 🔋 استثناء تحسينات البطارية + إرشادات البدء التلقائي لكل شركة (شاومي/هواوي/سامسونج/أوبو/فيفو/ون بلس)
- ♻️ إعادة تشغيل ذاتية بعد السحب من قائمة التطبيقات الحديثة

### 7. النسخ الاحتياطي والاستعادة (مدموج)
- 💾 تصدير JSON ببصمة SHA-256 للتحقق من السلامة
- 📥 استيراد بوضعين: **دمج** أو **استبدال كامل** + إعدادات الأمان
- 🤝 يقبل نسخ احتياطية من تطبيق "مراقب الاستخدام" القديم (توافق خلفي)

### 8. تجربة الاستخدام
- 🎨 **5 ثيمات فاخرة**: Midnight Prestige · Emerald Vault · Rose Aristocrat · Onyx Platinum · Sapphire Crown
- 🌐 **لغتان كاملتان**: الإنجليزية والعربية (كل الميزات المدموجة تُرجمت بالكامل) + RTL
- 🧭 **شريط تنقل سفلي موحد**: الرئيسية 🏠 / الاستخدام 📊 / البيانات 🌐 / القيود 🚫 + المعرض والإعدادات بالأعلى
- 🧙‍♂️ معالج إعداد شفاف بخطوات حية (الإشعارات → PIN → إمكانية الوصول → مسؤول الجهاز → البطارية)
- 📡 بدون إنترنت إطلاقًا — كل شيء على الجهاز (لا صلاحية INTERNET)

## 🏗️ القرارات المعمارية في الدمج

| القرار | التنفيذ |
|---|---|
| **الواجهات** | كلها XML Views تقليدية — الرسوم البيانية Custom Views مرسومة يدويًا (HourlyUsageBarChartView · TimeOfDayDistributionView) |
| **خدمة إمكانية الوصول** | خدمة موحدة واحدة `ScreenGuardAccessibilityService` تجمع محرك اللقطات + محرك الحجب + مكافحة العبث — صلاحية واحدة للمستخدم |
| **الأمان** | كائن واحد `PinManager` موسّع بكل ميزات SecurityRepository + تحقق مزدوج من صيغة التشفير (توافق ترقية) |
| **الهوية** | `com.screenguard.app` · الإصدار 3.0.0 (versionCode 8) |
| **التخزين** | SharedPreferences + JSON (نفس نمط التطبيقين، بلا قواعد بيانات) |
| **التنقل** | `MainTabsActivity` + BottomNavigationView + 4 Fragments |

## 🔨 متطلبات البناء

- **Android Studio** Hedgehog أو أحدث (أو سطر أوامر فقط)
- **JDK 17**
- **Android SDK**: Platform 34 + Build-Tools 34.0.0
- Gradle 8.6 + AGP 8.4.1 + Kotlin 1.9.23 (يُنزَّل تلقائيًا عبر الـ Wrapper)

### البناء من سطر الأوامر
```bash
# على لينكس/ماك
export ANDROID_HOME=/path/to/android-sdk
./gradlew assembleRelease
# الناتج: app/build/outputs/apk/release/app-release.apk
```

على Windows استخدم `gradlew.bat assembleRelease`.

> 🔑 ملاحظة التوقيع: المشروع موقّع بمخزن المفاتيح المرفق `keystore/release.keystore`
> (كلمة السر `screenguard123`، الاسم المستعار `screenguard`).
> **للنشر على المتاجر أنشئ مخزن مفاتيح خاصًا بك** وحدّث القيم في `app/build.gradle.kts`.

### البناء من Android Studio
افتح مجلد المشروع → انتظر مزامنة Gradle → `Build ▸ Generate Signed APK` أو شغّل مباشرة ▶️.

## 📲 التثبيت على الهاتف (خطوات الصلاحيات)

بعد التثبيت اتبع معالج الإعداد:
1. **الإشعارات** — لعرض إشعار المراقبة الدائم
2. **رمز الحماية PIN** — سؤال استعادة إلزامي للإنقاذ
3. **إمكانية الوصول** — صلاحية واحدة تشغّل: اللقطات + الحجب الفوري + مكافحة العبث
4. **مسؤول الجهاز** — لمنع إزالة التطبيق وقفل الشاشة
5. **استثناء البطارية** — لضمان عدم إيقاف النظام للمراقبة
6. **الوصول لبيانات الاستخدام** — تُمنح من قسم "الاستخدام" عند أول فتح (للتحليلات والقيود الزمنية)
