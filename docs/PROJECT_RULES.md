# قواعد المشروع الأساسية (Project Rules)

1. **الحديث باللغة العربية دائماً**: كل الحوارات، التعليقات المهمة، والواجهات موجهة بالعربية وواضحة تماماً للمستخدم العربي.
2. **حدود الإخراج البرمجي**: لا تتجاوز 1000 سطر برمجي في الدفعة الواحدة لتفادي اقتطاع الردود.
3. **الامتثال الصارم لمعايير نظام أندرويد**:
   - استخدام `MediaProjectionManager` وخدمة الواجهة الأمامية `ForegroundService` بنوع `mediaProjection`.
   - طلب أذونات النظام الشفافة (`POST_NOTIFICATIONS` و موافقة المستخدم الصريحة لمشاركة الشاشة).
   - عدم استخدام أي حيل التفافية أو خلفيات مشبوهة قد تؤدي لرفض التطبيق أو حظره من قبل نظام الحماية Google Play Protect.
4. **التركيز على وظيفة واحدة وبسيطة**: تجنب أي تعقيد معماري غير مبرر. لا حاجة لمكتبات ثقيلة أو خدمات سحابية.
5. **الاستقرار والمتانة (Resilience)**:
   - معالجة حالات نفاذ المساحة قبل حفظ الصور.
   - التعامل المرن مع توقف الجلسة من قبل النظام أو المستخدم (عبر `MediaProjection.Callback`).
   - تنظيف الذاكرة وموارد الصور (`Image.close()`, `Bitmap.recycle()`) فوراً لمنع تسريب الذاكرة (Memory Leaks).
