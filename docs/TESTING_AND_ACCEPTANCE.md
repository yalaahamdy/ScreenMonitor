# خطة الاختبار ومعايير القبول (Testing & Acceptance Criteria)

| الحالة الاختبارية | الإجراء المتوقع | معيار القبول |
| :--- | :--- | :--- |
| **1. الإعداد الأولي** | فتح التطبيق لأول مرة | يطلب تعيين رمز PIN مكون من 4-6 أرقام ويؤكده، ثم يحفظه مشفراً. |
| **2. قفل التطبيق** | الخروج من التطبيق وإعادة فتحه | تظهر شاشة القفل وتمنع الوصول لأي واجهة أخرى حتى إدخال الرمز الصحيح. |
| **3. محاولات خاطئة متكررة** | إدخال 5 رموز غير صحيحة | يتم تعطيل الإدخال لمدة 30 ثانية مع عداد تنازلي ورسالة تحذيرية واضحة. |
| **4. بدء المراقبة** | النقر على تشغيل المراقبة | يطلب نظام أندرويد إذن تسجيل/مشاركة الشاشة، تظهر خدمة الواجهة الأمامية بإشعار دائم، ويبدأ المؤقت. |
| **5. التقاط دوري** | ضبط الفاصل على 30 ثانية | يتم التقاط صورة شاشة وحفظها كل 30 ثانية بصمت تام دون أصوات أو إزعاج. |
| **6. استعراض اللقطات** | الدخول لمعرض التطبيق | تظهر الصور مرتبة من الأحدث إلى الأقدم مع تاريخ ووقت الالتقاط وإمكانية تكبيرها. |
| **7. تغيير الفاصل الزمني** | تعديل الفاصل الزمني أثناء أو قبل التشغيل | ينعكس الفاصل الزمني الجديد فوراً في جدولة الالتقاط القادم. |
| **8. سياسة الاحتفاظ** | ضبط مدة الاحتفاظ إلى يوم واحد مثلاً | يتم مسح أي لقطة يتجاوز عمرها المدة المحددة تلقائياً بعد كل عملية التقاط. |
| **9. انخفاض مساحة التخزين** | المساحة المتوفرة أقل من 50 ميجابايت | يتوقف الحفظ المؤقت بأمان مع تنبيه المستخدم دون انهيار التطبيق. |
| **10. إيقاف المراقبة** | النقر على إيقاف (من التطبيق أو الإشعار) | يتم تحرير الموارد (`VirtualDisplay`, `MediaProjection`) وإيقاف الخدمة والإشعار فوراً. |
